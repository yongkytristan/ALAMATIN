# Evidence index (ALM-038)

Every number this project may report, mapped to the artifact that supports it,
the exact path inside that artifact, and the script that produced it.

Generated by `scripts/build_evidence_index.py`. **Values are read from the
artifacts at build time and are never typed into the index**, so it cannot drift
from the evidence.

```bash
python scripts/build_evidence_index.py --verify
```

Two checks run, and both must pass:

1. every claim resolves to a real value in a real artifact;
2. **every document citing a claim contains the value the artifact actually
   holds** — so a stale number in prose fails a check instead of sitting there
   looking authoritative.

The second check earned its place immediately: it caught two latency figures in
`docs/ablation-and-latency.md` that were written before the ablation was re-run,
and a claim pointing at a status count that is absent because it is zero. Both
are fixed, and the latency table is now regenerated from the artifact.

Current state: **15 measured, 6 not measured, 0 problems**.

## User-study analysis

`scripts/analyze_user_study.py` computes medians, critical-error recall, false
defects, correct-decision rate, usability scores, permitted quotes, and protocol
deviations, split by condition.

It currently reports `not_measured`, because no session has been run. It emits
**no placeholder figures**: a dash or a zero in a results table reads as a
finding. The analysis path itself is tested with synthetic records, so it is not
left untested until the day it matters.

When data exists, the harness reports medians and the full range rather than a
confidence interval, and states plainly that the sample cannot support an
inferential claim.

## Rules this index enforces

- A number may appear in a document only if it is in this index.
- No target, goal, or placeholder may be presented as a result.
- Any claim about delivery success, returns, or failed deliveries is recorded as
  out of scope: nothing in this project measures a downstream outcome.
- Figures from the fine-tuned NER model describe a system that is **not
  served**; the release candidate runs `regex-baseline-v1.2`.
