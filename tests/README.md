# Tests

Place unit, integration, privacy, schema, and reproducibility tests here. Tests
must use synthetic or explicitly public fixtures and must never embed customer
addresses, phone numbers, credentials, or other private information.

The reference-hierarchy CSV fixtures are synthetic contract examples. They test
valid parent chains, ambiguous names, aliases, and cross-source conflicts; they
must not be treated as a government-data snapshot or Pos Indonesia evidence.

Postal pipeline tests also cover the full API audit controls, tiered consensus,
unresolved grouping, selected spot-check queues, governed final package, and
human-review worksheet preparation without mutating processed build outputs.
